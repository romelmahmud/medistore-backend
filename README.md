# 💊 MediStore Backend

**MediStore Backend** is a RESTful API server built with **Node.js**, **Express**, **PostgreSQL**, and **TypeScript**. It powers the MediStore frontend with endpoints for products, orders, users, authentication, and image uploads.

> 🔗 Frontend: [MediStore Frontend](https://medistore-frontend-pi.vercel.app)  
> 🌐 Live Backend: [MediStore Backend](https://medistore-backend-11jb.onrender.com)

---

## 💡 Features

- 🧑‍⚕️ User authentication (sign up, login, JWT)
- 💊 Manage medicines/products (CRUD)
- 🛒 Handle orders and cart operations
- ☁️ Image uploads via Cloudinary
- ⚡ Type-safe API using TypeScript
- 📦 Structured for scalability with Express + Prisma

---

## 🧱 Tech Stack

- **Node.js** & **Express.js**
- **TypeScript** for type safety
- **Prisma** ORM with **PostgreSQL**
- **Cloudinary** for media management
- **Render** deployment ready
